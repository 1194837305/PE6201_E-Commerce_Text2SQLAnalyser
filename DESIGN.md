# InsightSQL Design Context

InsightSQL is a bilingual e-commerce BI workspace for analysts. It uses dark navy navigation, a cool-gray workspace, white bordered panels, blue primary actions, green healthy states, and red errors. English is the default; Chinese is persistent via the header switch.

The information order is KPI overview, overview charts, AI question, result visualization, SQL, then raw rows. The source rail lists every queryable table and supports additive CSV uploads. AI answers always expose read-only SQL and result-grounded insights. Loading, empty, success, and failure states remain visible in context.

Uploaded identifiers are normalized. Generated SQL cannot write data or access SQLite system tables. Responsive layouts preserve the same analytical reading order.
